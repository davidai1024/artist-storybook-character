# Artist Storybook Character

**从日常事物出发，探索角色的不同可能。**

一套用于 AI 图像创作的角色设计 Skill。通过统一的艺术语言，把动物、物品、职业、动作或情绪转化为独立角色；想象力来自轮廓、比例与结构，而不是给通用吉祥物添加配饰。

## 视觉特点

- **手绘细线**：清晰的近黑色轮廓，保留自然的手绘感。
- **独特结构**：通过比例、姿态与负空间形成辨识度。
- **鲜明哑光配色**：干净的色块，不依赖渐变、光泽或脏纹理。
- **克制的表情**：微小的面部细节，安静而有趣。

## 使用方式

1. 将本仓库加入支持自定义 Skill 的 AI 助手；按该助手的说明导入 `SKILL.md`。
2. 如果助手没有 Skill 导入功能，可让它读取 `SKILL.md` 并按其中的指令执行。
3. 给出完整的角色描述，例如：`背着相机的红熊猫`、`安静的水壶`、`穿雨衣的鸭子`。
4. 助手计算配色指令，填入固定主提示，并调用其图像生成能力。

同一次输入作为一个完整角色概念处理。需要多个独立角色时，请明确要求分别生成。

本仓库提供创作指令，**不是独立的图像模型、应用或渲染服务**。使用环境须具备图像生成能力；工具参数和输出目录需按实际环境适配。`4K` 是目标设置，是否支持由所用服务决定。

## 输出规范

| 项目 | 要求 |
| --- | --- |
| 构图 | 默认 1:1，单个角色，轮廓完整，四周留白 |
| 背景 | 不透明纯白色 `#FFFFFF`，不使用透明底或棋盘格 |
| 文件 | PNG 位图；不宣称 SVG 或矢量可编辑性 |
| 表面 | 均匀色块，避免纸张噪点、斑驳与脏纹理 |

## 配色与一致性

Skill 根据输入文字的 UTF-8 字节计算 SHA-256，并生成三组 HSL 配色指令。相同的精确输入得到相同的**配色指令**，不同输入通常会得到不同配色；用户明确指定的颜色优先。

配色计算并不保证每次生成像素一致，也不保证图像模型精确遵守色值。更换模型或重复生成，角色造型可能变化。背景、轮廓和配色仍需验收。

默认每次独立创作，不借用之前生成的形象。只有在当前请求中明确提供参考图并要求参考创作时，才使用该参考。
